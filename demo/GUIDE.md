# Demo 使用與判讀說明

線上版：https://ecg-missingness.streamlit.app

本機執行：

```bash
pip install -r demo/requirements.txt
streamlit run demo/app.py
```

Demo 只用 **40 筆預先存好的代表樣本**（全部來自 fold 10 測試集，模型從未在訓練時看過），
int16 µV 無損儲存，共 0.67 MB；PTB-XL 資料集本身不進 repo。

## 一、左邊的控制項在動什麼

每一項給兩種說法：**白話**是講給沒有技術背景的人聽的，**技術**是被追問時要說得出來的。

| 控制項 | 白話 | 技術 |
|---|---|---|
| **樣本** | 換一張心電圖。括號裡是這張圖的正確答案，所以你隨時知道模型有沒有答對 | 從 40 筆代表樣本取一筆，皆屬 fold 10 |
| **導程** | 換一個角度看同一顆心臟。**只影響你看到的線，不影響模型判斷**——模型一直看全部 12 個導程 | 純視覺化選擇；特徵抽取與推論始終用完整 (1000, 12) 陣列 |
| **缺失型態** | 資料是「怎麼」缺的。散布＝到處掉一點；連續＝整段不見；訊號相關＝專挑心跳最強的地方缺 | scatter 與 burst 在 Rubin 分類下**都是 MCAR**，差別只在空間結構。MNAR 以 0.2 s 視窗的峰對峰振幅的 α=2 次方為權重抽樣（實測被遮區段振幅為保留區段的 1.82 倍） |
| **缺失率** | 總共缺掉多少 | 固定遮掉 `round(p·T)` 個點，非機率式生成——後者會讓實際缺失率帶抽樣波動。實測誤差 0.00000 |
| **缺口段數 k** | 同樣缺這麼多，是集中一大塊還是散成好幾小塊 | 段長 `n_missing // k`，餘數平均分配，總量精確；位置抽樣後展開保證不重疊。k→200 時每段剩 1 點，**依定義等於 scatter** |
| **補值方法** | 怎麼把缺掉的地方填回去。零填補＝填零線；前值填補＝拉成水平線；線性內插＝兩端拉直線 | 三種都只碰缺失點，觀測點改動數 = 0。零填補在被遮點上的 RMSE 必然約等於訊號 RMS（0.247 mV），是**理論地板** |
| **隨機種子** | 缺失的「位置」重抽一次。缺多少不變，只是缺在別的地方 | 這正是主圖誤差帶反映的隨機源——不是訓練的隨機性 |
| **可容忍的 AUROC 損失** | **你願意接受多少誤差**。決定畫面上方是綠燈還是紅燈 | 預設 0.03，門檻表另有 0.01 的嚴格版。這個值該由臨床風險決定，所以做成可調 |

## 二、畫面上的數字，看到多少算好

| 指標 | 方向 | 白話 | 技術 |
|---|---|---|---|
| **預期 AUROC 損失** | ↓ 越低越好 | 最重要的數字。0.003 幾乎沒差；0.03 是常用容忍線；到 0.09 就是「不能信」 | 不是這一筆算出來的，是從 213 次評估的傷害表依目前設定內插——**族群層級的期望損失**，不是個別誤差 |
| **綠燈／紅燈** | 綠 = 可信 | 紅色代表**正確處置是標記為不可用，而不是硬補完照常判讀** | 上一項與容忍上限比大小 |
| **實際缺失率** | — 中性 | 確認滑桿真的生效 | 與設定值誤差為 0 |
| **最長缺口** | ↓ 越短越好 | 超過 0.2 秒大概吃掉一次心跳；超過 0.84 秒就是一整個心動週期消失 | 三個 SQI 候選中，高傷害情境下守門表現最好的一個（覆蓋 40% 時 AUROC 0.847 → 0.896），且**完全不看標籤** |
| **缺口段數** | — 中間最糟 | **不是越少越好也不是越多越好**。切成 5–20 段時傷害最大，兩端反而輕 | 非單調，且**目前無法解釋**：三個假設全部被自己的資料否證（見 `notes/process_and_decisions.md` 的 F7） |
| **模型的信心 %** | ⚠ 陷阱 | **不要用它判斷資料好不好。** 模型在完全錯誤時一樣可以有 97% 的信心 | 機率輸出反映特徵落在決策邊界的哪一側，與輸入品質無關——這正是為什麼需要一個**獨立於模型之外**的品質分數 |

## 三、三個一定要親手拉一次的設定

**1. 樣本 #10（ecg_id 5753）· 訊號相關 MNAR · 缺失率 20%**
乾淨時模型 99.1% 確定正常；注入缺失後翻成 75.7% 確定異常。
同一筆資料、同一個模型，只因為缺了 20%，結論就跳到另一邊——**而模型本身不會告訴你這件事發生了。**

**2. 先「隨機散布 + 零填補」，再切到「連續大段 + 零填補」**
同一個補值方法，換個缺失結構就從最差變最好（損失 0.038 → 0.003）。
機制可驗證：散布型下零填補在每個缺失點製造一次高頻人工不連續，而模型第二重要的特徵正是
15–40 Hz 相對功率（實測某筆訊號該頻帶功率由 0.128 升到 0.331）。
**實務建議因此是反直覺的：缺失越集中、越與訊號相關，越不該用內插去猜。**

**3. 連續大段 · 缺失率固定 20% · k 從 1 拉到 50**
k=1（一整段 2 秒不見）反而比 k=10（切成十段各 0.2 秒）輕。這個現象重複驗證過，
三個假設都被自己的資料否證，**到現在還沒有解釋**。

## 四、四個容易講錯的地方

**✕「損失小，就代表這個補值方法補得好。」**
訊號補得像不代表模型判讀得對。訊號層的重建誤差排序與下游 AUROC 的排序**翻轉點不在同一個位置**
——這代表「補值品質」這個常用指標，跟真正重要的下游表現是脫節的。

**✕「模型信心高，所以這筆可以信。」**
反例就在畫面上：97% 的信心配上完全錯誤的答案。信心來自特徵落在決策邊界的哪一側，跟輸入品質無關。

**✕「守門後 AUROC 0.896 比乾淨基線 0.889 還高，所以守門讓模型變強了。」**
那是**選樣效應**——被留下來的樣本本來就比較好判。守門不會讓模型變強，
它只是讓模型不要回答它答不好的那些。

**✕「我做了 MCAR、MAR、MNAR 三種機制。」**
統計上錯了。**隨機散布與連續大段同屬 MCAR**，差別只在空間結構，只有第三種是 MNAR。
正確的說法反而更有力：「在同一個機制之下，光是缺失的結構不同，下游傷害就差 37 倍
——這件事單看機制分類是看不出來的。」
